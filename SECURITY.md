# Security Policy

## Supported versions

Security fixes are made for the **latest release** only. The program checks for updates
once a day (unless turned off on the About page) and offers to install new releases, so please
update before reporting a problem.

| Version | Supported |
|---|---|
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues, pull requests or
discussions.**

Report them privately instead, in one of these ways:

* **GitHub (preferred):** open the repository's **Security** tab and click
  **[Report a vulnerability](../../security/advisories/new)**.
* **Email:** send the details to **contact@softromeda.com** with "Security" in the subject.

Please include:

* the version of Softromeda Screen Recorder and of Windows;
* what kind of problem it is and what an attacker could do with it;
* steps to reproduce it, and a proof of concept if you have one.

## What happens next

1. We confirm that we received your report within **5 working days**.
2. We investigate, and keep you informed of progress and of our assessment.
3. When a fix is ready, we publish a new release and a security advisory. We credit you in the
   advisory unless you prefer to stay anonymous.

Please give us reasonable time to release a fix before sharing details of the vulnerability
publicly.
